Boolean logic was born in electronics. A wire either carries current or it does not, and gates combine wires into new wires. Picturing an expression as a circuit is a powerful way to see why it gives the value it does.

Reading the circuit

The circuit below implements the expression (P ∧ Q) ∨ ¬R. Read it from the inputs on the left to the output on the right.

  • Inputs P and Q feed an AND gate. Its output is on only when both inputs are on.
  • Input R passes through a NOT gate, so its output is on when R is off.
  • An OR gate joins the two results. The final output is on when either branch is on.

A worked assignment

Let P = T, Q = T, R = T. The AND branch gives T. The NOT branch gives ¬T = F. The OR gate sees T and F, so the output is T. Notice that one live branch is enough.

Now flip R to F. The AND branch is still T, and the NOT branch also becomes T. The output stays T. Which single change would make the output false? Keep that question in mind.

Your turn

Toggle P, Q, and R on the circuit and watch which wires light up. For each of the eight combinations, say out loud which branch is responsible for the output. Look for the combinations where neither branch is on, because those are the only ones that give a false output.

Key idea: an OR gate is false only when both of its inputs are false. To understand a compound condition, ask which branch carries the result.
