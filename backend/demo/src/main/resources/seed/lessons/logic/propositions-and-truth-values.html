Every if in your code asks a question that has exactly one answer: yes or no. Logic is the tool we use to reason about those answers before the program ever runs. The first step is to know what counts as a question worth reasoning about.

What is a proposition?

A proposition is a declarative statement that is either true or false, never both and never neither. Its answer is called its truth value, written T (true) or F (false).

  • “The server is running.” is a proposition. It is true or false at any moment.
  • “7 is greater than 10.” is a proposition. Its truth value is F.
  • “Restart the server.” is not a proposition. It is a command.
  • “Is the file saved?” is not a proposition. It is a question.
  • “x + 2 = 9” is not a proposition until x has a value.

Naming propositions

To work with several statements at once we give each one a letter such as P, Q, and R. Always write down what each letter means, so the final expression can still be read in the language of the original problem.

P: the user is logged in
Q: the account is verified
R: the request comes from the office network

A statement that cannot be split into smaller propositions is atomic. Statements built from atomic ones with words such as “and”, “or”, and “not” are compound. The next lesson shows how compound statements get their truth values.

Key idea: a proposition has exactly one truth value at a time. If you cannot decide whether a sentence is true or false, it is not yet a proposition.

Common mistakes

  • Treating opinions such as “this function is elegant” as propositions. They have no fixed truth value.
  • Forgetting that a false statement is still a proposition. “2 + 2 = 5” is a perfectly good proposition with value F.

In a program, a boolean variable is simply a proposition stored in memory. Learning to combine them correctly is what the rest of this course is about.
