Sometimes you need to talk about all the possible subsets of a set at once. Think of every possible combination of toppings on a pizza, or every possible set of permissions you could grant a user. The collection of all subsets is called the power set.

Definition

The power set of A, written P(A), is the set of all subsets of A, including the empty set and A itself. Its elements are themselves sets.

Building one

Let A = {1, 2}. List subsets by size:

size 0:  ∅
size 1:  {1}, {2}
size 2:  {1, 2}

P(A) = { ∅, {1}, {2}, {1, 2} }

So P(A) has four elements. Notice that {1} is an element of P(A) (it is a subset of A) but 1 is not an element of P(A). And A itself is an element of P(A), because A is a subset of itself.

A systematic method

  1. Start with the empty set.
  2. Add all subsets with one member, then two members, and so on.
  3. Finish with A itself.

Working by size prevents missing a subset and helps you spot the pattern that leads to a formula in the next lesson.

Key idea: elements of a power set are subsets of the original set.

Use this idea in the check: list every subset of A = {1, 2} first, then judge each statement.
