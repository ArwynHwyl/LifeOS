A quick check that the formula has become automatic. You will be asked for the number of elements in a power set given the size of the original set.

Remember

  • The size of the set is n, its number of members.
  • The size of its power set is 2ⁿ, the number of subsets.

It is easy to answer with n itself by mistake. Slow down and ask: “am I being asked how many members the set has, or how many subsets?” The power set counts subsets.

Example

A set with 3 members has 2³ = 8 subsets, so its power set has 8 elements. Use the same reasoning for the set in the checkpoint.
