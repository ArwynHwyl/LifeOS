Listing subsets by hand becomes hopeless quickly: a set with 10 members has more than a thousand. Fortunately there is a neat formula that counts them without listing.

Two choices per member

To build a subset, go through the members one at a time and decide for each: in or out. That is two choices for every member, and the choices are independent. With n members you multiply 2 by itself n times:

number of subsets = 2 × 2 × … × 2 = 2ⁿ

Checking small cases

n = 0:  2⁰ = 1    (only the empty set)
n = 1:  2¹ = 2
n = 2:  2² = 4    (matches P({1, 2}) from the last lesson)
n = 3:  2³ = 8
n = 4:  2⁴ = 16

Related counts

  • Non-empty subsets: 2ⁿ − 1 (remove the empty set).
  • Proper subsets: 2ⁿ − 1 as well (remove the set itself).
  • Subsets with exactly 2 members: n(n − 1)/2. Choose a first member, then a different second, then divide by 2 because order does not matter.
  • Subsets with exactly 3 members: n(n − 1)(n − 2)/6.
Key idea: every extra member doubles the number of subsets.
