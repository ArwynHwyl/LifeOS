Sets are the oldest and simplest idea in mathematics: a collection of distinct things. They quietly power databases, permissions, search filters, and the Set type in almost every programming language.

Definition

A set is a well-defined collection of objects, called its elements or members. “Well-defined” means that for any object you can say for certain whether it belongs or not.

Notation

  • We name sets with capital letters: A, B, C.
  • We list elements inside braces: A = {1, 2, 3}.
  • We write 2 ∈ A to say “2 is an element of A”, and 5 ∉ A to say “5 is not”.
  • Order does not matter, and repeats are ignored: {1, 2, 3} and {3, 1, 2, 2} are the same set.

Two ways to describe a set

  • Roster form: list the members, such as {2, 4, 6, 8}.
  • Set-builder form: state a rule, such as {x | x is an even number less than 10}. Read the bar as “such that”.

The empty set

The empty set, written ∅ or {}, has no elements at all. It is still a set. Think of an empty folder: the folder exists even though nothing is inside.

Key idea: a set is the whole collection, while an element is one member of it. The set A = {1, 2, 3} has three elements, but it is a single set.
