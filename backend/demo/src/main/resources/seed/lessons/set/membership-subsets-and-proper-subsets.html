Two questions come up again and again: “is this thing in the set?” and “is this set inside that set?” They look similar but use different symbols and mean different things. Mixing them up is the most common mistake in set theory.

Membership: element and set

Membership relates an element to a set with the symbol ∈. For A = {1, 2, 3}:

  • 2 ∈ A is true.
  • 4 ∈ A is false, so we write 4 ∉ A.

Subsets: set and set

Set B is a subset of A, written B ⊆ A, when every element of B is also an element of A. Note the wording “every element”: a subset is defined element by element.

  • {2} ⊆ A is true, because 2 is in A.
  • {1, 3} ⊆ A is true.
  • {1, 4} ⊆ A is false, because 4 is not in A.
  • ∅ ⊆ A is true for every set A, since there is no element that could fail.
  • A ⊆ A is always true: every set is a subset of itself.

Proper subsets

B is a proper subset of A, written B ⊂ A, when B ⊆ A and B is not equal to A. So A itself is a subset of A but never a proper subset of A.

Element or subset?

The braces make all the difference. 2 is a number, an element. {2} is a set that contains the number 2. So we say 2 ∈ A but {2} ⊆ A. Writing “2 ⊆ A” or “{2} ∈ A” is a category error.

Key idea: elements use membership (∈). Sets use subset language (⊆, ⊂).
