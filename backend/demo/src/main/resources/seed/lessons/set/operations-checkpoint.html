Before counting members, make sure you can read the operation symbols quickly and accurately. Each has a plain-language meaning that you can use as a memory aid.

Quick translations

  • A ∪ B means “A or B” (either, or both).
  • A ∩ B means “A and B” (both at once).
  • A − B means “A but not B”.
  • A′ means “not A”.

Notice the link to logic: union behaves like OR, intersection like AND, and complement like NOT. The same laws you meet in logic, such as De Morgan’s laws, work for sets too.

A tip for the checkpoint

Ask yourself what a member must satisfy. If the question says an element must be in both sets at the same time, it is asking for the operation whose symbol looks like a cup that is closed on top: ∩.
