With three sets, the same idea applies but the overlaps get richer: three pairwise overlaps and one region in the very middle where all three circles meet. Counting carefully requires the inclusion-exclusion principle.

Why simple addition fails

Add n(A) + n(B) + n(C). Members in exactly two sets are counted twice, and members in all three are counted three times. We fix this in two moves:

  1. Exclude the pairwise overlaps: subtract n(A ∩ B), n(A ∩ C), n(B ∩ C). But now the three-way middle was subtracted three times, which removes it entirely.
  2. Include the three-way region again by adding n(A ∩ B ∩ C) back once.

The formula

The core formula is n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(A ∩ C) − n(B ∩ C) + n(A ∩ B ∩ C).

Example with the default values

Let n(U) = 60, n(A) = 24, n(B) = 22, n(C) = 18, n(A ∩ B) = 8, n(A ∩ C) = 6, n(B ∩ C) = 5, and n(A ∩ B ∩ C) = 2.

union   = 24 + 22 + 18 − 8 − 6 − 5 + 2 = 47
outside = 60 − 47 = 13
A only  = 24 − 8 − 6 + 2 = 12

The pattern for “only” regions: subtract both pairwise overlaps that touch the set, then add the middle back.

Key idea: add, subtract pairs, add the triple. Signs alternate.
