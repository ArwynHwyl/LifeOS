Now use the formula in reverse. Instead of asking “how many subsets does this set have?”, ask “how big must a set be to have this many subsets?” This is the same skill as estimating how many features can be combined before the options explode.

The challenge

Adjust n until the number of subsets, 2ⁿ, equals 32.

How to solve it

Because the formula uses powers of two, it helps to know them by heart:

2¹ = 2     2² = 4     2³ = 8     2⁴ = 16
2⁵ = 32    2⁶ = 64    2⁷ = 128   2⁸ = 256

Find 32 in the list and read off the exponent. You can also halve repeatedly: 32 → 16 → 8 → 4 → 2 → 1 takes five halvings, so n = 5.

Key idea: if a set has 2ⁿ subsets, halving the count n times reaches 1. The number of halvings is n.
