It is time to build a diagram yourself. Turning a word problem into a labelled Venn diagram is the most reliable way to avoid double counting.

The problem

Build a two-set Venn diagram for sets A and B.

Given: n(A) = 14, n(B) = 12, and n(A ∩ B) = 5.

Steps

  1. Add circle A and circle B, and arrange them so they overlap.
  2. Start with the overlap, because it is given directly: 5.
  3. Fill each “only” region by subtracting the overlap from the set total.

Target regions: A only = 9, B only = 7, and A ∩ B = 5.

Key idea: always fill the innermost region first, then work outward.

Check yourself: 9 + 5 = 14 members in A, and 7 + 5 = 12 members in B.
