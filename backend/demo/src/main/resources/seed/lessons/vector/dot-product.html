How much do two vectors point the same way? A single number can answer that: the dot product (also called the scalar product). It is the basis of everything from checking perpendicular lines to ranking search results by similarity.

Two equivalent formulas

With components, multiply matching components and add:

a · b = a₁b₁ + a₂b₂ + a₃b₃

With geometry, use the angle θ between the vectors:

a · b = |a| |b| cos θ

Both give the same number. The first is easier to compute, the second explains what the number means.

Worked example

For a = ⟨2, 3⟩ and b = ⟨4, −1⟩:

a · b = 2×4 + 3×(−1) = 8 − 3 = 5

What the sign tells you

  • Positive: the vectors point in broadly the same direction (angle below 90°).
  • Zero: the vectors are perpendicular (angle exactly 90°).
  • Negative: the vectors point in broadly opposite directions (angle above 90°).

Finding an angle

Rearranging the geometric formula gives cos θ = (a · b) / (|a| |b|). That is how software measures the angle between two directions.

Key idea: a dot product of zero is the test for perpendicular vectors.

Note that the answer is a plain number, not a vector, and that a · b = b · a.
