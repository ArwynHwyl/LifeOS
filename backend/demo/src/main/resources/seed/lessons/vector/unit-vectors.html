Often you care only about a direction, not a length: which way is the wind blowing, which way is the light shining? A vector of length exactly 1 captures pure direction, and it is called a unit vector.

Standard unit vectors

The unit vectors along the coordinate axes are so useful that they get their own names:

  • i = ⟨1, 0, 0⟩ points along the x-axis.
  • j = ⟨0, 1, 0⟩ points along the y-axis.
  • k = ⟨0, 0, 1⟩ points along the z-axis.

Any vector can be written using them: ⟨3, 4, 2⟩ = 3i + 4j + 2k.

Normalising a vector

To get the unit vector in the direction of a, divide each component by the magnitude:

û = a / |a|

Example: a = ⟨3, 4⟩ has |a| = 5, so û = ⟨3/5, 4/5⟩ = ⟨0.6, 0.8⟩. Check: 0.6² + 0.8² = 0.36 + 0.64 = 1.

Why it matters

  • Game characters move at a fixed speed in any direction: multiply a unit direction vector by the speed.
  • Lighting calculations use unit normal vectors so that lengths do not distort the result.
  • Splitting a vector into direction × size makes formulas easier to reason about.
Key idea: dividing a vector by its own length keeps its direction and sets its length to 1.

The zero vector has no direction, so it cannot be normalised. In code, check for a length of zero before dividing.
