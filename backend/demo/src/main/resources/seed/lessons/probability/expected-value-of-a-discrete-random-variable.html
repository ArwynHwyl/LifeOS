If you played a game a thousand times, how much would you win on average per game? The answer is called the expected value. It is the long-run average, and it is how casinos, insurers, and product teams decide whether something is worth doing.

The formula

Multiply each value by its probability, then add:

E(X) = Σ x · P(x) = x₁P(x₁) + x₂P(x₂) + …

The result is often written μ (the Greek letter mu), the mean of the distribution.

Example 1: a fair die

E(X) = 1(1/6) + 2(1/6) + 3(1/6) + 4(1/6) + 5(1/6) + 6(1/6)
     = 21/6 = 3.5

You can never roll 3.5, but over many rolls the average approaches 3.5. The expected value need not be a possible outcome.

Example 2: a game

A ticket costs 20 baht. You win 100 baht with probability 0.1 and nothing otherwise. The net result X is +80 with probability 0.1 and −20 with probability 0.9.

E(X) = 80(0.1) + (−20)(0.9) = 8 − 18 = −10

On average you lose 10 baht per play. A game is fair when E(X) = 0.

Handy rules

  • E(aX + b) = a·E(X) + b. Scaling and shifting the values scales and shifts the mean the same way.
  • E(X + Y) = E(X) + E(Y), even if X and Y are dependent.
Key idea: the expected value is a probability-weighted average, the balance point of the distribution.
