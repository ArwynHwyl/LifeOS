Insurance companies, game designers, and weather services all do the same thing: they take an uncertain outcome and describe exactly how likely each possibility is. The tool for this is the probability distribution.

Random variables

A random variable X assigns a number to each outcome of a random experiment. Roll a die and let X be the number showing. Flip three coins and let X be the number of heads. The word “discrete” means the possible values can be listed, such as 0, 1, 2, 3.

The distribution

A probability distribution lists every possible value x together with its probability P(X = x). For a fair six-sided die:

x       1    2    3    4    5    6
P(x)   1/6  1/6  1/6  1/6  1/6  1/6

Two rules every distribution must satisfy

  1. Each probability is between 0 and 1 (inclusive). A negative probability or one greater than 1 is impossible.
  2. The probabilities add up to exactly 1, because something must happen.

Testing a list

  • 0.2, 0.3, 0.5 → all between 0 and 1, and 0.2 + 0.3 + 0.5 = 1.0. Valid.
  • 0.5, 0.7, 0.2 → sum is 1.4. Too large. Invalid.
  • −0.1, 0.6, 0.5 → contains a negative value. Invalid.
  • 0.1, 0.2, 0.4 → sum is 0.7. Too small. Invalid.
Key idea: a valid distribution has no negative probabilities and totals exactly 1.

Use both rules in the check, one list at a time, and look for the only list that passes them.
