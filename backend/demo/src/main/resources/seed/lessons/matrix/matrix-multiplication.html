Adding matrices is straightforward. Multiplying them is where matrices become powerful, and where the rules become unlike ordinary numbers. Multiplication combines information across rows and columns, which is exactly what is needed to chain transformations, such as rotating and then scaling an image.

When is it defined?

Matrix multiplication is defined only when the number of columns of the first matrix equals the number of rows of the second. If A is m × n and B is n × p, then AB exists and has size m × p.

The row-times-column rule

Each entry of AB is found by pairing a row of A with a column of B, multiplying matching entries, and adding the products.

A = [ 1  2 ]      B = [ 5  6 ]
    [ 3  4 ]          [ 7  8 ]

AB = [ 1×5 + 2×7    1×6 + 2×8 ]   [ 19  22 ]
     [ 3×5 + 4×7    3×6 + 4×8 ] = [ 43  50 ]

The top-left entry is row 1 of A paired with column 1 of B: 1×5 + 2×7 = 19.

Surprising properties

  • Order matters. In general AB ≠ BA. Here BA = [[23, 34], [31, 46]], which is different.
  • Identity: AI = IA = A, so I plays the role of the number 1.
  • Associative: (AB)C = A(BC), so you can group products as you like.
  • A product can be zero even when neither matrix is zero.
Key idea: to multiply, go across a row of the first matrix and down a column of the second.

Always check the sizes first. A 2 × 3 matrix times a 3 × 4 matrix works and gives a 2 × 4 matrix. Reverse the order and it does not work at all.
