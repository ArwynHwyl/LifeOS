A spreadsheet, a photograph, a table of exam scores: all of them are grids of numbers. Mathematics gives such grids a name, the matrix, and a whole set of rules for calculating with them. Graphics cards, search engines, and machine learning are built on matrix arithmetic.

What is a matrix?

A matrix is a rectangular arrangement of numbers in rows (horizontal) and columns (vertical). Each number is an entry.

A = [ 1  2  3 ]
    [ 4  5  6 ]

Its size is written rows × columns. This matrix is 2 × 3: two rows and three columns. An entry is named a_ij, where i is the row and j is the column. Here a_23 = 6 (row 2, column 3).

Special matrices

  • Square matrix: the same number of rows and columns, such as 2 × 2.
  • Row matrix and column matrix: a single row or a single column.
  • Zero matrix: every entry is 0.
  • Identity matrix I: ones on the main diagonal and zeros elsewhere. It acts like the number 1 for matrices.

Equality and basic operations

Two matrices are equal when they have the same size and every matching entry is equal. Addition, subtraction, and scalar multiplication work entry by entry:

[ 1  2 ]   [ 5  0 ]   [ 6  2 ]        [ 1  2 ]   [ 3  6 ]
[ 3  4 ] + [ 1  7 ] = [ 4 11 ]      3 [ 3  4 ] = [ 9 12 ]

Adding requires the same size. A 2 × 3 matrix cannot be added to a 3 × 2 matrix.

Key idea: a matrix is a table of numbers with a size, and the size decides which operations are allowed.
