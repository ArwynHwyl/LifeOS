Now put inverses to work. Matrix equations look like the equations you already know, such as 3x = 12, but the unknown is a matrix. The same strategy applies: undo whatever was done to the unknown, one step at a time. The only new rule is that the order of multiplication matters.

Solving AX = B

To free X, multiply both sides by A⁻¹ on the left:

AX = B
A⁻¹AX = A⁻¹B
IX = A⁻¹B
X = A⁻¹B

Because matrix multiplication is not commutative, you must put A⁻¹ on the same side on both sides of the equation. If the unknown is on the left instead (XA = B), multiply by A⁻¹ on the right: X = BA⁻¹.

Example

Solve AX = B with A = [[3, 1], [2, 4]] and B = [[5], [6]]. From the last lesson, A⁻¹ = [[0.4, −0.1], [−0.2, 0.3]]. Then:

X = A⁻¹B = [ 0.4×5 + (−0.1)×6 ]   [ 1.4 ]
           [ −0.2×5 +  0.3 ×6 ] = [ 0.8 ]

Check: 3×1.4 + 1×0.8 = 5 and 2×1.4 + 4×0.8 = 6. Correct.

Common mistakes

  • Multiplying by A⁻¹ on the left of one side and the right of the other.
  • Trying to divide by a matrix. There is no such operation.
  • Forgetting to check that the determinant is nonzero first.
Key idea: to isolate the unknown, multiply by the inverse on the same side on both sides.
